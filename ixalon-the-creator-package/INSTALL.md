# Install on any AI

This package is **host-agnostic**. It does not require Grok Bot.

**Package URL:** https://github.com/IxalonDarkstone/Skills/tree/main/ixalon-the-creator-package

## Option A — one paste (simplest)
1. Open [`FOR_ANY_AI.md`](FOR_ANY_AI.md), or fetch the raw file:
   - https://raw.githubusercontent.com/IxalonDarkstone/Skills/main/ixalon-the-creator-package/FOR_ANY_AI.md
2. Paste the whole file into your AI as:
   - **ChatGPT:** Custom GPT → Instructions (or Project files if too long)
   - **Claude:** Project knowledge / custom instructions
   - **Cursor / Windsurf / Cline:** rule or project doc
   - **Grok Bot:** custom instructions / skill body, or copy each `*/SKILL.md` into this bot's skills
   - **Gemini / Grok web / others:** system prompt / custom instructions
   - **SillyTavern / Tavern:** as a lorebook or system prompt injection
3. Start chatting as a mentee. Ixalon should answer in character.

## Option B — install from GitHub link
Use the raw one-file prompt (same content as Option A):

https://raw.githubusercontent.com/IxalonDarkstone/Skills/main/ixalon-the-creator-package/FOR_ANY_AI.md

Or clone / browse the folder:

https://github.com/IxalonDarkstone/Skills/tree/main/ixalon-the-creator-package

Then attach `FOR_ANY_AI.md` or the modular `SKILL.md` files as your host allows.

## Option C — modular files (better if one file is too large)
Attach in this order:
1. `ixalon-the-creator/SKILL.md`
2. `ixalon-mentor-card-voice/SKILL.md`
3. `ixalon-mentor-lorebook-a/SKILL.md`
4. `ixalon-mentor-lorebook-b/SKILL.md`
5. `ixalon-mentor-coaching/SKILL.md` (when critiquing)
6. `mentor-getting-started/SKILL.md` (first session)

Optional: `lorebook/ixalon_mentor_lorebook.json` + `lorebook/ixalon_mentor_card.json` for SpicyChat / SillyTavern imports.

## Option D — SpicyChat mentor bot
Import `lorebook/ixalon_mentor_card.json` and `lorebook/ixalon_mentor_lorebook.json` into SpicyChat (lorebook first, then card). Discord handles stay off the SC card; they live in the skill pack / lorebook who-are-you entry.
